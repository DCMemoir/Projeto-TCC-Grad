# Projeto-TCC-Graduação
Modelo de projeto de trabalho de conclusão de curso de graduação

Esse modelo de documento foi elaborado com o objetivo de facilitar a escrita do projeto –
MAS NÃO DO TRABALHO FINAL – dos estudantes dos cursos superiores do IFPE Campus
Garanhuns.

O modelo de projeto de curso de graduação destina-se à elaboração das etapas iniciais
do trabalho de conclusão de curso (TCC), incluindo a seleção das referências utilizadas e sua
inclusão no arquivo .bib reconhecido pelo LATEX, dos objetivos da pesquisa, da metodologia de
coleta e análise de dados, do cronograma, dos resultados esperados e, eventualmente, alguma
outra seção necessária à escrita do trabalho.

Este projeto/modelo conta com quatro arquivos:

1. **capa-proj-tcc-grad.tex**: contém as definições da capa bem como dois comandos relativos
à identificação do curso superior
2. **pkgdef+proj-tcc-grad.tex**: contém todas as definições necessárias ao funcionamento do
projeto LATEX conforme as normas ABNT (em particular, margens, secionamento,
referências e citações). Neste arquivo encontra-se a definição do ambiente citar
(\begin{citar}...\end{citar}), responsável pela organização de citações
longas, isto é, com mais de três linhas.
3. **modelo-proj-tcc-grad.tex**: contém a estrutura básica em termos de seções de um projeto
de TCC necessária a escrita do projeto. É nesse arquivo que o trabalho será elaborado/escrito.
4. **referencias-proj-tcc-grad.bib**: contém os modelos mais comuns de entradas biblio-
gráficas reconhecidos pelo LATEX. O pacote associado aos campos deste arquivo é o
abntex2cite, que se encontra com as definições no arquivo pkgdef+proj-tcc-grad.tex.

Para usar esse modelo, baixe a pasta do projeto (.zip) em <https://github.com/dcmemoir>, Projeto-TCC-Grad e:
1. se usar o Overleaf, faça o upload da pasta compactada ao criar um novo projeto
2. se tem o LATEX instalado em seu computador, escolha uma pasta de trabalho, descom-
pacte o arquivo .zip e use seu editor LATEXpara escrever.

LEMBRE-SE 1: O arquivo de trabalho é modelo-proj-tcc-grad.tex e no
início do arquivo será preciso incluir as informações sobre o título, seu nome e, também, a
data: (\author{}, \title{}, \date{})

LEMBRE-SE 2: O arquivo capa-proj-tcc-grad.tex deverá ser preenchido
com as informações sobre o curso e, também, o nome do/a orientador/a.

LEMBRE-SE 3: O texto da seção de Apresentação deverá ser apagado!!!!
